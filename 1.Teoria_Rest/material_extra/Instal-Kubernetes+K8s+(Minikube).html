Instalação do Minikube no Ubuntu

Este passo a passo ensina como instalar o kubectl (cliente do Kubernetes) e o Minikube (cluster local Kubernetes) no Ubuntu. Cada comando está descrito com sua função para facilitar o entendimento.

1. Atualizar o sistema e instalar dependências

sudo apt update
sudo apt install -y curl apt-transport-https

Explicação: Atualiza a lista de pacotes disponíveis e instala o curl (usado para baixar arquivos) e o suporte a HTTPS nos repositórios APT.

2. Instalar o kubectl

curl -LO "https://dl.k8s.io/release/$(curl -Ls https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/kubectl
kubectl version --client

Explicação: Faz o download da versão estável do kubectl, dá permissão de execução, move o binário para o diretório de execução do sistema e testa a instalação.

3. Instalar o Minikube

curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube
rm minikube-linux-amd64
minikube version

Explicação: Baixa o Minikube, instala no sistema, remove o arquivo temporário e verifica a versão instalada.

4. Iniciar o cluster Kubernetes local

minikube start
kubectl get nodes

Explicação: Inicializa o Minikube com as configurações padrão e usa o kubectl para verificar se o nó (node) do cluster está ativo.

5. Testar com um pod NGINX

kubectl run nginx --image=nginx
kubectl get pods

Explicação: Cria um pod executando a imagem nginx e lista os pods para confirmar que ele está em execução corretamente.
